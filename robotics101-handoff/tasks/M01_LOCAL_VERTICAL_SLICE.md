# M01 — local vertical slice (highest priority)

## Goal
Given `examples/episode-001.json`, produce an end-to-end **local** artifact bundle with 16:9 H.264 MP4, AAC audio, synchronized SRT, scene clips, manifest and QA report. Keep interfaces pluggable for AI/TTS/cloud later.

## Deliverables
1. Python package/CLI: `robotics101 validate <episode.json>` and `robotics101 render <episode.json> --out out/episode-001` (or documented equivalent).
2. JSON Schema validation, scene sequence/total-duration validation and template selection registry.
3. Manim reusable minimal templates for intro, robot anatomy, sensor range, sense-think-act, servo, recap.
4. Headless Blender minimal mobile robot scene: obstacle detection, stop, turn, resume. Use primitive geometry, no downloaded assets.
5. Per-scene narration adapter: support fixture synthesized/placeholder voice with explicit label; external TTS optional through env config. Do not fake human narration as a working TTS integration.
6. Scene timing based on audio duration (with pauses/holds); FFmpeg concat/crossfade only when safe and tested; SRT generation.
7. `ffprobe` automated quality checks: codec, size, FPS, audio, total duration and playable output. SHA-256 manifest.
8. `Makefile` or scripts + README local prerequisites and reproducible commands, `.gitignore` for generated artifacts.
9. Automated tests: schema parse, no invalid/duplicate scene order, kinematics or sensor geometry test, rendering CLI smoke test (optional flag if dependencies absent), invalid asset rejection.

## Clarification on sample
The sample storyboard narration is intentionally brief to exercise structured contracts. For a true five-minute pilot, **expand each scene's narration** to match its intended runtime before publishing; in a fixture demo, silence/holds may fill gaps but cannot count as successful educational pacing. Flag this distinction in QA.

## Acceptance criteria
- No service secrets required to run validate and template tests.
- Render path documents required installed versions and checks binaries.
- Deterministic run from the sample spec produces all output artifacts, and `ffprobe` confirms 1920x1080, 30fps, H.264/AAC (provide optional low-res preview mode for speed).
- Total duration between 270 and 330 s; QA explicitly warns if voice content is too short or fixture audio used.
- Does not invoke any YouTube upload or create cloud resources.
- 3D segment is generated by Blender and 2D scenes by Manim; hybrid footage is demonstrable.
- No generated Python is executed outside isolated worker runtime in production architecture.
